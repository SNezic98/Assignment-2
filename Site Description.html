{My name is Samuel Nezic, this is my typeface website.}
{This typeface is largely based on coding language typography. But rather than going for a basic
code-like design, i decided to go for a more sinister theme. A cold, unfeeling, manipulative code bent
on domination and manipulation. The entire design follows the feeling of cold and distant code with an
unerving undertone. The usage of binary throughout the design is fully translatable and reveals more
about the underarching story, though more deveopment will be needed.}
{The typeface is: Anonymous by Mark Simonson. The following is a link to his website: https://fonts.adobe.com/foundries/mark-simonson-studio}
